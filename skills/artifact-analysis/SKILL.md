# artifact-analysis
Preservar los artefactos originales. Tratar la Matriz como fuente de casos. Relacionar cada caso con evidencia EF/ET. Clasificar hechos como CONFIRMADO, POR_VALIDAR, GAP o CONFLICTO. No crear requisitos ausentes.
