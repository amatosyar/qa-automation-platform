# Auto-LDS assessment

## Adoptar conceptualmente
- memoria central verificable y versionada;
- registro de consultas;
- bootstrap de requerimientos;
- evidencia/resultados estructurados;
- intervencion humana;
- extraccion de Matriz/EF/ET.

## Adaptar
- runners y reportes al ecosistema Playwright/Python;
- parsers como adapters por formato;
- conocimiento en scope central + proyecto.

## No generalizar
- `web_lds_core.py` y modulos de dominio LDS;
- scripts CP autonomos como patron universal;
- credenciales embebidas;
- waits fijos como solucion estandar;
- acoplamiento a Claude como runtime obligatorio.
